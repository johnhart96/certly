How to trust this CA

Chrome / Edge (Windows) — open the .crt, choose Install Certificate → Local Machine → Trusted Root Certification Authorities.

macOS (Safari, Chrome) — open the .crt in Keychain Access, add it to System, then double-click it and set When using this certificate to Always Trust.

Firefox — Settings → Privacy & Security → View Certificates → Authorities → Import, and tick “Trust this CA to identify websites”.

Linux (Chrome) — Settings → Privacy and security → Security → Manage certificates → Authorities → Import.

Linux (system)

sudo cp certly-local-ca.crt /usr/local/share/ca-certificates/
sudo update-ca-certificates

Check the SHA-256 fingerprint above matches before trusting it.
